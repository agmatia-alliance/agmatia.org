# Projects

We care about practical software, dependable systems, and useful open work. This page is for things that are ready to share, not a long list of promises. We'll add project write-ups as the work gets a stable public home.

## Areas we keep coming back to

Projects vary, but we tend to gravitate toward problems where a small, well-made tool or a clearer system can make a real difference.

## How we choose what to build

We look for a clear need, a scope we can explain, and a result that will be useful after the first release. If an idea doesn't meet those basics yet, we'll keep exploring rather than dress it up as a finished project.

## See our public work

The latest public work lives on [GitHub](https://github.com/agmatia). We'd rather add a project here when there's something real to show than fill the page with promises.
